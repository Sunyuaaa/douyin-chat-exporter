# 抖音聊天记录导出器（内置 WebView2 · 接口直连）

> 读取聊天数据的核心逻辑参考 [TeamBreakerr/douyin-chat-export](https://github.com/TeamBreakerr/douyin-chat-export)（308★，未附许可证），详见文末「参考与致谢」。

一个精简的 WebView2 桌面软件：软件内直接打开抖音网页版、**扫码登录**，然后**直接调用抖音 IM 的
protobuf 接口翻页拉全量私信**（不模拟滚动、不抓 DOM），一键导出为 JSON / HTML / TXT / CSV；
还能把聊天里的**图片 / 自拍视频 / 语音 / 表情下载到本地（自动解密）**，导出的 HTML 直接内嵌可离线播放的媒体。
渲染内核复用 Windows 自带的 WebView2 Runtime（Chromium），程序本体约 30 MB。

**界面与导出特性：**

- **v1.1 全新界面**：扫码登录成功后自动进入「完整版」风格的全屏操作界面——左侧 40px 图标竖栏
  （选会话 / 概览 / 聊天记录 / AI 分析 / 设置），右侧步骤卡片；🌐 一键回到抖音网页，左上角胶囊随时唤回面板。
- 会话列表按「**全部 / 私聊 / 群聊**」筛选与搜索，支持全选；每个会话显示真实**头像 + 昵称**。
- 导出支持**时间范围**（全部 / 近 3 个月 / 自定义日期）与**媒体类型勾选**（图片/视频/语音/表情）。
  选「自定义」时起止日期与三个按钮**同一行靠右**显示，点日期弹的是**阅读器同款自绘日历**
  （不再用系统 `input[type=date]`；未来日期不可选，起 > 止 会自动对齐）。
- **不显示的空内容有三类**（统一由 `isJunkRow` 判定）：接口就没给正文的（`blank`）、**打招呼卡片**
  （`greeting`）、以及**文字类但一个字符都没有**（以前会渲染成「[空]」气泡）和
  **只有时间没有正文的系统通知**（渲染出占位词「系统消息」的那批，撤回/版本提示那一堆）。
  阅读器与 HTML / TXT / CSV 里都不出现；JSON 留底仍是全量，并给这类消息打上 `blank` / `greeting` 标记。
  界面上不额外提示隐藏条数，需要时到「会话详情」里查。
- 导出格式：JSON / HTML（微信式气泡）/ TXT / CSV；JSON 字段最全，是唯一的完整留底。
- **语音转文字**（可选）：是导出前的独立一步，**四种格式都会带上**——JSON 的 `asr` 字段、
  TXT 的「（转文字：…）」、CSV 内容列的「[语音 8秒] 转文字：…」、HTML 与阅读器的语音下方；
  不勾 HTML 也会转，与格式勾选顺序无关。设置里填 OpenAI 兼容的 Base URL / API Key / 模型名即可。
  抖音语音是 m4a，而部分网关（如 MiMo）的 `input_audio` 只接受 wav/mp3——软件会自动用
  ffmpeg 转码后再上传。查找顺序是 **系统 PATH → 程序目录里的 `ffmpeg.exe` → pip 的
  `imageio-ffmpeg`**：exe 版没有 venv，装系统 ffmpeg 或把单文件 `ffmpeg.exe` 丢到 exe 旁边即可
  （`imageio-ffmpeg` 自带 87MB 二进制，为控制体积有意没打进包，见 spec 注释）。
  都没有时界面上直接给出可操作的提示，而不是丢一个 400。
- **转写被限流会自动退避重试**（429 / 5xx / 网络异常最多 4 次，429 优先按 `Retry-After` 等待），
  并发也降到 2；参数类错误（400）不重试。转好的文字**重启软件后依然显示**——每次导出、打开阅读器
  都会先把语音旁同名 `.txt` 回填进来，所以再导出一次也不会把 JSON 里已有的 `asr` 冲成空。
  只想补跑失败的那些：阅读器右上角「语音转文字」默认就只勾了未转写的。
- **任何图片解不出来都不会留破图标**：浏览器画不出来的图（HEIC 没转码成功、文件损坏、CDN 过期），
  阅读器与导出 HTML 里统一处理——分享卡片的封面**整块删掉**只留介绍，消息本身就是那张图的
  换成灰字「图片无法显示」（HEIC 会写明「HEIC 未转码成功」），内联小表情退回显示 `[流泪]` 这样的文字，
  头像解不出来则保留首字母圆。实现上给每个 `<img>` 挂 `onerror`，导出 HTML 另加一个捕获阶段的
  全局 error 监听兜底。
- **HEIC 不再被误存成 `.mp4`**（破图标的根因之一）：`plain` 任务原先只看 `ftyp` 盒就判定视频，
  而 iOS 的 HEIC/HEIF 图片同样是 `ftyp`，于是图片被存成 `.mp4`，`<img>` 自然解不出来。
  现在按 brand 区分（`media._HEIF_BRANDS`），HEIF 走转 JPEG、失败才留 `.heic` 并往 `boot.log` 记一行。
  `download_one` 的「已存在就跳过」也加了自愈：0 字节文件、以及**内容是图片却叫 `.mp4`** 的旧坏文件
  会被删掉重下，所以老数据里已经存坏的图下次导出会自动修好。
- 图片 / 视频 / 表情 / 语音 / **分享视频卡片**在阅读器与导出 HTML 里**直接显示**，不再套气泡底色，
  卡片本身也不带边框白底；文字消息仍是气泡样式。分享卡片的视频介绍换成**衬线小灰字**，
  跟聊天正文一眼分开；**封面缺失或链接过期时整块不显示**，只留介绍与「▶ 打开视频」。
- **只导了 JSON 也能就地补下媒体**：阅读器打开一条记录时若发现图片 / 视频 / 语音 / 表情还没下载，
  工具栏「标题 → 搜索框」之间会出现一条提示（如「媒体未下载 · 图片 2 · 语音 2 · 表情 1」）
  和一个「⬇ 下载 N 项」按钮，点了就走同一套下载管线（并发 6、视频先 `batch_play_info` 换地址、
  尊重加密分支），完成后**只把 `local` / `coverLocal` 两个字段写回该会话的 JSON**（不重导消息，
  所以隐藏消息、`asr` 都不会被冲掉），再自动刷新视图，提示条随之消失。
  `mediaTasksFor(会话名, 消息, opts)` 是这份任务表的唯一出处，导出与补下载共用，加一类媒体不会漏一处。
- **软件内阅读聊天记录**：日期分组、搜索、按日期跳转，图片/语音/视频/头像经本地桥懒加载，离线可读。
  左侧列表来源 = 本次已获取的会话 + `exports/` 里已导出的会话；**正在看的那条被删掉时**
  （在抖音里删会话、或清了 `exports/`），刷新列表会把右侧一起复位成「这条记录已经不在了」，
  不再出现「左边写着没有记录、右边还停在旧会话」的错位（`readerResetView()`）。
  工具栏含 按日期跳转（日历打点）/ 图片浏览 / 语音下载 / **语音转文字** / 表情包导出 / 会话详情；
  **表情包合集按表情资源去重**（同一个表情发几十次只显示一张，远程地址的 `?签名` 参数不参与区分）；
  工具栏最右侧不再显示「N 条」计数（条数在左侧列表的名字后面，隐藏了几条去「会话详情」查）；
  图片浏览支持**双击放大**；四个弹层（图片浏览 / 语音下载 / 表情包 / 语音转文字）右上角都有
  一个**时间排序箭头**：↓ 最新在前、↑ 最早在前，点一下切一次，选择自动记住（四处共用同一个开关）。
- **获取与导出进度改为毛玻璃弹窗**：转写、下载媒体、分块写文件都在弹窗里实时显示，
  **进度条按整体阶段推进**（转写 20% + 各格式 × 各会话 × 会话内阶段），
  新任务开始时会从 0 重新计（不保留上一次的 100% 往回缩）。
  获取阶段可在弹窗里点「停止获取」；导出期间弹窗保持遮挡，跑完自动关闭。
  **底部的行内进度条、两行进度文字、以及那行红色流水日志全部删掉**：进度只看弹窗，
  失败信息改由 toast 提示（`log()` 里带「失败/错误」字样的才弹，2 秒内同样的话不重复弹），
  那块区域平时整块隐藏，只在真的有事做时出现一条橙色「获取中…请稍候」。
- **中途停止后可以继续取**：会话是否「取完」由 `state.pullDone` 记录（翻到 `hasMore=0` 才算），
  停止 / 连续网络错误 / 撞到 400 页上限都算未取完。再点「▶ 获取聊天数据」会**从未取完的会话、
  以已有最早一条消息的时间戳为游标继续往前翻**，已有数据不丢也不重复；会话列表里显示
  「已取一部分 · 可继续获取」。修复前的表现是：停止后再点被判定「数据已就绪」，剩下的永远取不到。
- 转码 / 视频处理等外部命令一律以 **无控制台窗口** 方式运行，不会每转一条语音闪一个 cmd 黑框。
- 概览页「最近导出」每条带**会话头像**（按落盘名回查会话；查不到或图挂了退回首字母圆）。
- **原生标题栏跟随界面主题**：底色 / 文字色 / 边框色按 `--bg`、`--text` 同步（Win11 的
  `DWMWA_CAPTION_COLOR`，Win10 不支持时静默跳过，只是回到系统默认白框），不再出现「白框 + 灰界面」；
  图标有浅/深两套描边（`app-icon.ico` / `app-icon-dark.ico`），切主题时一起换，深色栏上不会看不见。
- 左竖栏新增 **AI 分析** 入口（人物性格 / 好感度那类），当前只是占位页，进去显示「正在开发中，敬请期待」。
- 前置步骤未完成的按钮**不再点了没反应**：依旧置灰，但点击会弹窗说明下一步该做什么（约 2 秒自动消失）；
  步骤条完成态改为**浅绿**填充。
- 获取完成后**自动保存 JSON 快照**，重启后阅读器仍可打开；JSON 字段新增 server_id / 发送者昵称 / 媒体路径。
- 导出 HTML 为**微信式气泡**：每条带头像、显示**真实发送时间**、小表情直接渲染成图片。
- **分享的抖音视频不下载视频本体**，只保存封面、标题、作者和链接；仅下载你与对方实拍 / 直发的视频。
  阅读器里点「▶ 打开视频」走 `target="_self"`，**在本软件窗口内跳转**（`_blank` 会被 WebView2
  丢给系统默认浏览器）；导出的 HTML 里仍是新标签页打开（那是在真浏览器里看）。
- **看完视频点左上角回到刚才那份记录和位置**：跳转前把「在看哪个会话、哪条消息、滚到哪」写进
  `localStorage`（键 `dyce_return_intent`，12 小时有效、只认一次），并带上跳转前的 URL；
  新页面加载时登录检测**不再自动弹出导出面板**，胶囊改写成「▲ 返回聊天记录 · 会话名」，
  点它 → 进阅读器 → 内存视图已随页面刷新丢失则自动改读 `exports/` 的 JSON 快照 → 滚到那条消息。
  还停在原页面（URL 没变，例如重启软件）时意图作废，走正常流程。
- **概览页三个数字按「本机已有」统计**：`app.overview_stats()` 扫 `exports/`，消息数取每个会话
  JSON 头部的 `meta.total`、媒体数取 `media/**` 下的文件数（`.txt` 转写缓存与 `.zip` 打包结果不计入），
  再与本次会话内存里的值取较大者。修复前只数内存，重启软件后本机明明有几千条却显示 0。
- 步骤条**单调**：前一步没完成时，后面的 ✓ 与绿色连线一律不显示（以前选时间范围时，
  后面会因为上次拉过数据先亮成绿色，看着像进度错乱）。
- 头部汇总**语音条数与总时长**；长 HTML **滚动到哪加载到哪**（分批渲染，数千上万条也不卡）。
- 大文件经**分块写入**落盘，避免单次传输超大内容导致程序崩溃。

## 目录结构与交接说明

```
DouyinExporter/
├─ DouyinExporter.exe   # 单文件成品（约 29MB，v1.1 已打包），双击即用；改源码后用文末命令重打一次
├─ app.py               # 程序源码（pywebview 外壳 + 导出/媒体落盘 + 密钥/登录态管理）
├─ media.py             # 媒体下载/解密（kind 注册表权威出处）：图片 AES-GCM、视频 CENC、语音、HEIC 转 JPEG
├─ injector.js          # 注入页面的核心：会话枚举 + IM 接口直连 + 媒体下载 + 四格式导出 + 全部界面
├─ im-schema.json       # 接口字段表 / aweType 类型表：抖音改版优先改这里，不用重编译
├─ emoji-map.json       # 文本里 [流泪] 这类内联小表情 → 图片地址
├─ app-icon.ico         # 标题栏/任务栏图标（浅色描边，配浅色主题）
├─ app-icon-dark.ico    # 同上，深色主题用的浅色描边版（否则黑底上看不见）
├─ test_media.py        # 媒体解密离线自检（8 例，不联网）
├─ test_export.py       # 落盘/密钥/登录态离线自检（不碰真实 Data/ 与 exports/）
├─ requirements.txt
├─ 启动.bat             # 源码方式启动（无 exe 时就用它）
├─ tools/               # 开发调试辅助（CDP 执行 JS / 截图 / 回归 / 分发前检查），产品运行不需要；
│                        使用前需设环境变量 DY_DEBUG=1 再启动（9222 调试口默认关闭）
├─ Data/                # 【本机私有】WebView2 登录态，扫码后自动生成
└─ exports/             # 【本机私有】导出的聊天文件（按人名分文件夹）
   └─ <人名>/            # 一个会话一个文件夹，html/json/txt/csv 与媒体同处其中
      ├─ <人名>.html     # 直接双击打开；发送到别人时整个文件夹打包即可
      └─ media/{images,videos,voice,emoji,shares,avatars}/        # 本地媒体与头像
```

> **交接 / 拷贝给他人或公开发布前：务必删除 `Data/`、`exports/`、`boot.log`。**
> `Data/` 内含你的登录 Cookie（拿到的人可直接进入你的抖音账号，`Data/llm_config.json` 里还有模型
> Key——新版已用 Windows DPAPI 加密，旧版可能是明文），`exports/` 内含你的聊天内容，
> `boot.log` 会暴露会话名与统计。exe 与源码本身不含任何个人信息。
> 别靠记忆清点，跑一次检查：`.\.venv\Scripts\python.exe tools\precheck_release.py`
> （只读检查，会列出必须删的东西和结论）。接手者首次使用自行扫码登录即可。

## 直接使用（推荐）

> 本目录已随附打好的单文件成品 **`DouyinExporter.exe`**（v1.1，约 29MB），双击即用。
> 不想用 exe（或改了源码想立刻生效）就**双击 `启动.bat`**——首次会自动建 `.venv` 并装依赖，
> 行为与成品完全一致。重新打包的命令见文末「自行打包」。

1. 双击 `DouyinExporter.exe`（单文件、免安装）。单文件版首次启动需几秒到十几秒解压运行时，属正常，期间不要重复双击；启动后在 exe 同目录生成 `Data/`（登录数据）和 `exports/`（导出文件）。**同一时间只开一个实例**，多开会争抢 `Data/` 里的 WebView2 单例锁。
2. 软件打开后是抖音网页版，**用手机抖音 App 扫码登录**。登录态保存在程序目录 `Data/`，以后打开免扫码（便携，整个文件夹拷走即用）。
3. **登录成功后自动进入全屏操作界面**（左侧图标竖栏：选会话 / 概览 / 聊天记录 / AI 分析 / 设置）。
   左侧列出会话（**头像 + 昵称**，支持搜索与 全部/私聊/群聊 筛选）；点 🌐 可回到抖音网页，
   回来时点左上角黑色胶囊重新打开面板。
4. 在列表里**点选要导出的会话**（可多选，也可「全选」；◎ 按钮加入网页里正打开的会话）。
5. 右侧设置**导出格式**（JSON / HTML / TXT / CSV 可多选）、**时间范围**与**媒体下载类型**，
   点「**▶ 获取聊天数据**」。软件直接向抖音 IM 接口翻页请求，左下角进度实时增长，`hasMore=0` 即拉完。
   完成后自动保存 JSON 快照（供「聊天记录」阅读器使用）。
6. 点绿色「**⬆ 导出**」：自动下载勾选类型的媒体（图片、实拍视频、语音、表情，
   以及分享视频的封面与信息，已有文件自动跳过）后按所选格式写入 `exports/<人名>/`；
   「步骤2 概览」可查看统计与最近导出，点「打开导出文件夹」直接查看。
   下载完成后再导出 HTML，网页里图片/视频/语音/表情直接内嵌、离线可播。
   **分享视频只存封面 + 标题 / 作者 / 链接，不下载视频本体。**
7. **阅读**：点左竖栏「聊天记录」图标，在软件内直接阅读已获取/已导出的记录
   （日期分组、搜索、按日期跳转、媒体懒加载）。换会话导出：回「步骤1」勾选其他会话重复即可。

### 前置条件

- Windows 10 / 11
- 已安装 **WebView2 Runtime**（Win11 自带；Win10 随 Edge 普遍具备；缺失时启动会弹窗提示，
  到微软官网装「Evergreen Standalone Installer」即可：https://developer.microsoft.com/microsoft-edge/webview2/ ）
- exe 放在**有写权限**的文件夹里（桌面、D 盘等；不要放 Program Files——`Data/`、`exports/` 要写在旁边）

### 首次运行的常见提示

- **SmartScreen 蓝色警告 / 杀毒误报**：未签名 exe 的正常现象，点「更多信息 → 仍要运行」或加白名单

## 导出格式

| 格式 | 用途 |
|---|---|
| JSON | 字段最全：时间、发送方、类型、文本、引用、原始 content，留底首选（界面隐藏的无内容 / 打招呼卡片也在其中，带 `blank` / `greeting` 标记） |
| HTML | 气泡样式归档；媒体下载后内嵌图片/视频/语音，离线双击阅读 |
| TXT | 纯文本 `[时间] 我/对方: 内容` |
| CSV | 带 BOM，Excel 直接打开不乱码 |

已覆盖消息类型：文本（含 @提及 / 富文本 712、720）、表情、图片、视频/图文/动图分享
（老结构 `itemId` 与新结构 `item_id + description` 都认）、评论/商品分享、语音、系统消息、打招呼卡片；
确实取不到正文的消息（撤回 / 客户端专有卡片）打上 `blank` 标记，界面与 HTML/TXT/CSV 默认不显示，
JSON 里仍保留原文与标记，不再显示成 `[未知]`。

## 媒体下载机制

| 媒体 | URL 来源 | 处理方式 |
|---|---|---|
| 图片（aweType 2702/2703/2704） | `resource_url.origin_url_list[0]` | AES-256-GCM（`resource_url.skey`，32B）解密；HEIC/HEIF 自动转 JPEG |
| 语音 | `resource_url.url_list[0]` | 不加密，直接下载 `.m4a`；时长取消息 `duration`，HTML 头部汇总总时长 |
| 自拍 / IM 视频 | `video.tkey` → `batch_play_info` | MPEG-CENC AES-128-CTR（`video.skey`，16B）逐 sample 解密 |
| 小表情（aweType 500/501/507/508/510…） | `url.url_list[0]` | 不加密，gif/png 直接下载；HTML 内渲染成图片 |
| **分享的抖音视频** | `itemId` / `cover_url` | **不下载 mp4**；只存封面 `shares/<sid>_cover.jpg` + 元信息 `<sid>_meta.json`（标题 / 作者 / 链接） |
| 头像 | IM `user/info` 的 `avatar_thumb` | 导出 HTML 前批量下载到 `avatars/`，气泡内离线显示 |
| 自拍视频封面 | `poster.origin_url_list` | 随视频一并下载（AES-GCM 解密） |

- 视频地址解析（`batch_play_info`、`aweme/detail`）在**页面上下文**用页面登录态 fetch；
  下载与解密在 Python 端完成。媒体按 `exports/<人名>/media/{images,videos,voice}/<server_id>.<ext>` 存放，与导出文件同目录，便于整文件夹打包。
- 已下载文件按 server_id 去重，重复点击只补缺失项；单个失败不影响其余，计数面板显示成功/跳过/失败。

## 工作原理

```
DouyinExporter.exe（Python + pywebview 外壳，约 15 MB，含 Python 运行时）
  ├─ 窗口、菜单、文件保存（Python）
  ├─ injector.js：页面加载后自动注入
  │    ├─ 等全局 MobX conversationStore，从 conversationMap 枚举全部会话
  │    ├─ 内置最小 protobuf 编解码，POST /v1/message/get_by_conversation
  │    ├─ 用会话 shortId + 响应 nextTs 翻页，直到 hasMore=0（全量）
  │    ├─ 页面内 fetch batch_play_info / aweme detail 解析视频地址
  │    ├─ aweType 渲染各类消息；悬浮面板
  │    └─ 导出 / 媒体任务经 pywebview 桥回传 Python
  ├─ media.py：媒体下载，图片 AES-GCM、视频 CENC 解密、HEIC 转 JPEG，落盘 exports/<人名>/media/
  └─ WebView2 控件 → 系统 WebView2 Runtime（Chromium：Blink/V8/网络/解码，不随程序分发）
```

- 复用页面自身登录态，请求由本软件在你的登录会话内发出；不向任何第三方地址上传数据。
- Cookie / 缓存保存在程序目录 `Data/`（已显式关闭 pywebview 的 private_mode，否则退出时该目录会被清空）；删除该目录即退出登录，齿轮里的「清除登录态」按钮会做这件事（下次启动生效）。
- 模型 API Key 用 Windows DPAPI（当前用户绑定）加密后存 `Data/llm_config.json`，界面与页面 JS 只能看到掩码；旧版明文在首次读取时自动迁移。
- 接口字段与消息类型集中在 `im-schema.json`（`app.py` 注入成 `window.__DYIN_SCHEMA`），
  `injector.js` 内置同值默认兜底；改版时改这个文件即可，未识别类型会往 `boot.log` 记 `[schema-miss]`。

### 关于时间戳

消息 protobuf 里有两个时间字段：

- `field 10`：**真实发送时间（毫秒）**，本软件的显示与排序都用它。
- `field 4`（`created_at_us`）：服务端**归一化压缩**的排序游标（大量消息挤在同一基准秒、微秒递增），仅用于翻页，不用于显示。

早期版本误用 field 4，会出现历史消息日期都挤在同一天的问题；现已改用 field 10，日期与实际一致。

## 故障排查

- **双击后白屏 / 标题“(未响应)”**：任务管理器结束所有 `DouyinExporter.exe` 及命令行含 DouyinExporter 的 `msedgewebview2.exe`，重新双击一次，等待 10–20 秒，不要连点；确认只开了一个实例。
- **面板一直“正在检测登录…”**：说明未登录，请在页面扫码登录后点「刷新会话列表」。
- **会话列表为空 / 数量不对**：点「刷新会话列表」；确认已进入能加载私信的页面。
- **拉取中途停止**：直接再点「开始全量拉取」会从头重拉；连续网络错误时面板会提示，检查网络 / 代理后重试。
- **面板不见了**：点左上角黑色胶囊「▲ 打开导出面板」，或刷新页面（会自动重新注入）。
- **想彻底重置登录态**：齿轮 →「清除登录态」，或直接删除程序目录 `Data/` 后重启。
- **导出提示「没能写入文件」**：说明落盘真的失败了（不会再假装成功）；内容已转成浏览器下载，
  把 `boot.log` 里的「分块落盘失败 / 导出落盘最终失败」两行发给维护者即可定位。
- **获取完显示 0 条 / 提示「接口字段可能已变更」**：看 `boot.log` 的 `[schema-miss]` 行，
  按里面列出的字段名补 `im-schema.json`；不用重新逆向页面。
- **语音转文字没出字**：`boot.log` 现在有 `[转文字失败] …原因`（HTTP 状态与返回片段），
  齿轮里点「▶ 测试」可当场验证接口通不通。
- **转文字只出了一部分**（例如 231 条只有 150 条有文字）：不是显示问题，是剩下的真的没转成功，
  日志里通常是 `导出前语音转写: 成功150 失败81 共231` + `HTTP 429`（网关限流）。
  现在会自动退避重试并把并发降到 2；仍有剩余就进阅读器 →「语音转文字」，弹窗默认只勾了未转写的，
  点「开始转写」补跑即可，已成功的直接命中 `.txt` 缓存、不会重复请求。

## 已知限制 / 未做

- 媒体下载依赖消息里的**签名 CDN URL**，链接已过期 / 消息已撤回 / 对方注销时无法补救；个别失败会在计数面板列出，重点可续下。
- iPhone 的 HEIC 图片会转 JPEG（依赖 pillow_heif，已随包收集）；极端情况下转换失败会保留 `.heic`。
- 会话昵称 / 头像通过 IM 批量接口获取；仅个别注销 / 异常账号接口返回空时，才兜底显示“单聊 + uid”。
- 分享视频的链接采用官方标准永久链接 `https://www.douyin.com/video/<itemId>`（可直接打开）；
  真正的 `v.douyin.com` 短链需 App 分享动作 / 签名生成，本软件未做。
- 大量视频 / 图片首次下载较占带宽与时间，可分多次点击，已下载部分自动跳过。
- 仅限备份本人账号数据，导出内容涉及对方隐私，请勿擅自公开传播。
