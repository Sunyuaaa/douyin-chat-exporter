抖音聊天记录导出器 v1.1 — 使用说明
====================================

【快速上手】
1. 双击 DouyinExporter.exe（或源码方式双击 启动.bat）
2. 如出现蓝色警告条：点「更多信息 → 仍要运行」
3. 软件内会打开抖音网页版，用手机抖音 App 扫码登录
4. 登录成功后自动进入操作界面（左侧图标竖栏 + 步骤导航）：
   · 步骤1「选会话」：左侧勾选会话（可多选、可搜索，支持 全部/私聊/群聊 筛选；
     「全选」一键勾选当前列表，◎ 按钮可加入网页里正打开的会话）
     右侧设置：导出格式（JSON/HTML/TXT/CSV 可多选）、时间范围（全部/近3个月/自定义）、
     媒体类型勾选（图片/视频/语音/表情，导出时按勾选自动下载）、导出位置
   · 「▶ 获取聊天数据」：开始翻页拉取，进度显示在毛玻璃弹窗里（弹窗内可点「停止获取」）；
     停止后再点一次会从未取完的会话继续往前翻，已拿到的不丢也不重复；
     完成后自动保存 JSON 快照（供阅读器离线阅读）
   · 「⬆ 导出」：自动下载勾选的媒体（已有文件跳过）后按所选格式写入
     exports/<会话名>/，概览页可查看最近导出
   · 步骤2「概览」：账号信息、已获取统计与最近导出（此页隐藏左侧会话列表）
   · 「聊天记录」：软件内直接阅读本机记录——左侧列表带头像，右侧日期分组、
     搜索、按日期跳转，图片/语音/头像点开即加载（经本地桥传输，离线可用）
     只导了 JSON 时媒体其实还没下载：这条记录的标题与搜索框之间会出现
     「媒体未下载 · 图片 2 · 语音 2 · 表情 1」和「⬇ 下载 N 项」按钮，
     点一下就把这些图片/视频/语音/表情下载下来，并把本地路径写回这条记录的 JSON，
     完成后自动刷新，提示条消失（下载过程走同一个进度弹窗）
   · 「AI 分析」：分析人物性格、对方对你有没有好感这类，目前还没做，
     点进去是一个占位页「正在开发中，敬请期待」
5. 点击左上角**头像**可回到抖音网页；再回来时点左上角黄色胶囊即可重新打开面板
6. 左竖栏底部齿轮：设置（导出位置、界面主题 白天/黑夜、语音转文字模型、
   「清除 Key」只删本机保存的 API Key、「清除登录态」需连点两次确认，下次启动生效；关于）
   · API Key 在本机是加密存放的（Windows 账号绑定），设置界面只显示掩码

【语音转文字】
0. 前提：抖音语音存下来是 m4a，而有些网关（如 MiMo）的接口只接受 wav/mp3，
   软件会自动用 ffmpeg 转码后再上传，所以本机要有 ffmpeg。按你的使用方式挑一个：
   · 用 DouyinExporter.exe：装一次系统 ffmpeg 并加入 PATH（如 winget install Gyan.FFmpeg），
     或者下载单文件版 ffmpeg.exe 直接放到 exe 同目录（软件会优先按这个顺序找）
   · 用 启动.bat（源码版）：在本目录执行  .\.venv\Scripts\python.exe -m pip install imageio-ffmpeg
   缺它时界面会直接告诉你怎么办，不会只丢一个 400。
1. 齿轮 →「语音转文字模型」：填 Base URL（OpenAI 兼容，如 https://…/v1）、API Key、
   模型名（默认 mimo-v2.5-asr），点「保存模型设置」
2. 步骤1 勾选「语音转文字」（在导出格式下面一行），会自动确保勾选「语音」
3. 点「⬇ 导出」：转写是导出前的独立一步（先确保语音已下载，再逐条转），
   结果缓存为语音旁的 .txt，并且**四种格式都会带上**——
   JSON 是 asr 字段；TXT 写成「[语音 5秒]（转文字：…）」；
   CSV 拼进内容列「[语音 5秒] 转文字：…」；HTML 与阅读器显示在语音气泡下方。
   不勾 HTML 也会转；与格式的勾选顺序无关。没配模型时会明确提示「语音未转写：模型未配置」。
4. 已转换过的语音不重复请求（缓存命中直接用）；关掉软件重开也已经转好的照样显示——
   每次导出和打开聊天记录都会先把语音旁的 .txt 读回来，不会把 JSON 里已有的文字冲掉
5. 偶尔限流：网关返回 HTTP 429（请求太频繁）时自动等待重试（最多 4 次），并发也已降到 2。
   如果日志里是「成功150 失败81 共231」这类，说明失败的确实还没转成，不是显示问题
6. 也可以只在「聊天记录」页里转：右上角「语音转文字」图标打开一个窗口，列出本机已下载的语音
   （默认只帮你勾上还没转写的，可「全选 / 仅选未转写」）→「开始转写」；结果即时显示在语音气泡下方，
   并自动写回该会话的 JSON 记录（以后导出的 JSON/HTML/TXT 都带文字）。
   补跑失败的走这里最省事：已成功的命中缓存，不会重复请求、不重复花钱

【与 1.0 的区别】
- 界面重构为「完整版」风格的全屏操作界面（原左上角悬浮小面板移除）
- 新增：时间范围筛选、按类型勾选下载媒体、软件内聊天记录阅读器
- 新增：左竖栏「AI 分析」入口（人物性格 / 好感度分析），当前为占位页「正在开发中，敬请期待」
- 新增：界面主题（白天 / 黑夜模式，选择自动记住）
- 获取/导出进度改为毛玻璃弹窗（含转写、下载媒体、写文件），进度条按整体阶段推进、
  新任务从 0 重新计；导出期间弹窗保持遮挡，跑完自动关闭
- 底部原来的行内进度条和「本次获取 N 条 / 媒体进度」两行删掉了（进度只看弹窗），
  那一块只剩「正在执行」提示与最近一条日志（失败原因会写在这里）
- 修掉一个 bug：获取中途点「停止获取」后，再点「获取聊天数据」会被当成「数据已就绪」而再也取不到
  剩下的；现在会从未取完的会话、接着已有最早一条继续往前翻（不丢、不重复），
  会话列表里这种条目显示「已取一部分 · 可继续获取」
- 表情包合集按表情本身去重（同一个表情发多少次都只显示一张）；阅读器右上角不再显示「N 条」
- 更严的「空内容不显示」：除了原来的无正文消息与打招呼卡片，**只有气泡没有字的「[空]」**和
  **只有时间没有正文的「系统消息」**（撤回提示、版本通知那一堆）也不再出现在阅读器与
  HTML/TXT/CSV 里；JSON 留底仍是全量
- 步骤1「时间范围」选自定义时，起止日期与「全部 / 最近 3 个月 / 自定义」同一行靠右显示；
  点日期弹出的是和「聊天记录 → 按日期跳转」同款的日历（不再是系统那个 yyyy/mm/日 控件），
  未来的日期不可选，开始日期选了会自动接着让你选结束日期
- 概览页「最近导出」每条前面加了会话头像
- 导出面板底部那行红色日志删了：进度本来就在毛玻璃弹窗里，那行平时只是攒流水；
  真失败时会改成弹 toast 提示，平时那块区域整个隐藏
- 阅读器里点「▶ 打开视频」改为**在本软件窗口内跳转**，不再弹出系统浏览器
  （导出的 HTML 文件里仍是新标签页打开，那是在真浏览器里看）
- 看完视频点左上角的黄色胶囊，会**直接回到刚才那份本地聊天记录和刚才看的位置**：
  跳转前会记住「在看哪个会话、哪条消息、滚到哪」，回到抖音后不再自动弹导出面板，
  胶囊上写着「▲ 返回聊天记录 · 会话名」；点它会重新打开那份记录（内存里的数据随页面刷新没了
  就自动改读 exports/ 的 JSON 快照）并滚到那条消息。这个记忆 12 小时内有效、只用一次
- 修掉概览页数字不对：以前只数本次会话内存里的数据，重启后本机明明有几千条却显示 0；
  现在按 exports/ 里的实际内容统计（消息数读 JSON 头部条数，媒体数数 media 目录里的文件，
  转写缓存 .txt 与打包的 .zip 不算媒体），和本次内存里的取较大者
- 步骤条改为单调：前一步没完成时后面的 ✓ 与绿色连线不再提前亮起（以前选时间范围时
  后面已经显示绿色对勾，看着像进度错乱）
- 转码语音时不再闪 cmd 黑框（外部命令一律无窗口运行）
- 窗口最上面的标题栏改成跟界面同色（白天浅灰 / 黑夜深灰），左上角图标换成新的简笔画图标
  （气泡 + 向下箭头）；深色主题会自动换成浅色描边那套图标，不然在黑底上看不见
- 没完成的步骤按钮不再是点了没反应：点击会弹窗提示下一步该做什么；步骤条完成勾改为浅绿
- 图片浏览新增双击放大；图片浏览 / 语音下载 / 表情包 / 语音转文字四个窗口右上角
  都有时间排序箭头（↓ 最新在前，↑ 最早在前，点一下切一次）；阅读器新增语音转文字入口
- 图片 / 语音 / 表情 / 视频 / 分享视频卡片一律直接显示，不套气泡底色，卡片自己也不带白框边线；
  分享卡片的视频介绍换成衬线小灰字，跟聊天正文一眼分开；封面缺失或链接过期时图片整块不显示，
  只留介绍和「▶ 打开视频」（普通图片读不到时仍会写「媒体缺失」，因为那条消息本身就是图片）
- 修掉「聊天记录」左右不一致：在抖音里删了会话（或清了 exports/）之后，左边列表已经显示
  「还没有记录」，右边却还停在之前打开的那个会话上；现在刷新列表会把右侧一起复位，
  显示「这条记录已经不在了（会话被删除或导出文件被清理）」，重新获取后再刷新会自动打开新记录
- 修掉「图片位置显示一个破图标 + 空框」：根因是 iOS 的 HEIC 图片和视频一样带 ftyp 头，
  旧代码见到 ftyp 就存成 .mp4，浏览器自然解不出来。现在按真实格式区分，并且
  「文件已存在就跳过下载」加了自愈——0 字节文件和「内容是图却叫 .mp4」的坏文件会删掉重下，
  老数据里存坏的图下次导出自动修好；万一还是解不出来（比如没装 HEIF 组件），
  分享卡片里的封面整块不显示，普通图片位置写「图片无法显示（HEIC 未转码成功）」，
  内联小表情退回显示 [流泪] 这样的文字，头像退回首字母圆，都不再留破图标
- 「聊天记录」左侧列表的条数挪到名字后面用括号显示，如「星河（4059 条）」；重启后只剩磁盘记录
  的条目也带条数（从 JSON 头部的 meta.total 读，不用整个文件解析）
- 修复一批消息显示：@提及富文本、新版分享卡片（图文/动图/商品）不再显示成原始长文本；
  确实没有正文的消息不再显示 [未知]，并且默认不出现在阅读器与 HTML/TXT/CSV 里
  （打招呼卡片同样隐藏）；JSON 留底仍是全量，这类消息带 blank / greeting 标记，
  具体隐藏了几条在「会话详情」里可查，界面上不做额外提示
- JSON 导出新增 server_id / 发送者昵称 / 本地媒体路径字段（阅读器数据源）
- 获取完成后自动保存 JSON 快照，重启软件后仍可在「聊天记录」里阅读

【遇到问题】
把本目录（或 exe 旁边）的 boot.log 文件发给分享给你的人即可远程分析。
现在失败原因也会写进日志：导出没落盘成功 → 「分块落盘失败 / 导出落盘最终失败」；
语音转写失败 → 「[转文字失败] …（含接口返回的错误）」；
抖音改版导致拉不到消息 → 「[schema-miss] …」，维护者按里面的字段名改 im-schema.json 就行。

【要求】
- Windows 10 / 11
- 如提示缺少 WebView2 运行时：按弹窗指引到微软官网安装一次即可
- 数据只保存在你自己电脑上，不上传任何第三方服务器

【注意】
- 同一时间只开一个实例
- 换电脑使用：把整个文件夹拷过去，重新扫码登录即可
- 仅限备份本人账号数据，请勿传播导出内容
